# VideoLab AI

Aplicación web progresiva para crear proyectos de video desde el navegador. No usa APIs externas ni envía imágenes a servidores. Los archivos se procesan localmente.

## Publicar con GitHub Pages
1. Subí todos los archivos y la carpeta `icons` a la raíz del repositorio.
2. En Settings > Pages, elegí Deploy from a branch, branch `main`, folder `/ (root)` y guardá.
3. Esperá la URL publicada.
4. En Safari del iPhone abrí la URL y elegí Compartir > Añadir a pantalla de inicio.

Nota: la exportación WebM depende de las funciones disponibles en el navegador. En iOS puede no estar soportada en todas las versiones.
